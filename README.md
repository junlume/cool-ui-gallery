## 文件怎么找

- 想看图片：进入每个案例目录里的 `preview` 或直接看上面的首页图片。
- 想看源码：进入 `app`。
- 想运行项目：打开对应 `app` 目录里的 README 或 `package.json`。

以后新增 UI，只添加一个新的案例文件夹，不把源码和预览图混在根目录。
