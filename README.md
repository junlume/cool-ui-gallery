# Cool UI Gallery

一个持续收集和组件化重建酷炫 UI 的仓库。

## Cases

### Payathon 2026 · Pay for AI
Vue 3 + Vite 活动页重建，包含 Hero、伙伴 Logo 带、收益卡片、赛道切换、流程区和横向活动日历。

- 源码：`showcase/payathon-2026/app/`
- 规格：`showcase/payathon-2026/UI-SPEC.md`
- 展示图：`showcase/payathon-2026/`

运行：

```bash
cd showcase/payathon-2026/app
npm install
npm run dev
```

### MOTDES · Motion design portfolio UI
一套 Astro + WebGL 动态作品集界面，包含流体背景、粒子 Profile、视频作品墙、服务案例、音效开关和滚动叙事。

- 完整项目：`showcase/motdes/motdes/`
- 展示素材：`showcase/motdes/motdes/public/`

运行：

```bash
cd showcase/motdes/motdes
npm install
npm run dev
```

每个案例独立保存源码、展示图、素材和说明，后续新增 UI 直接添加新的 `showcase/<slug>/` 目录。
