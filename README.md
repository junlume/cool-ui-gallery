# Cool UI Gallery

一个持续收集和组件化重建酷炫 UI 的仓库。

## Cases

### Payathon 2026 · Pay for AI
Vue 3 + Vite 活动页重建，包含 Hero、伙伴 Logo 带、收益卡片、赛道切换、流程区和横向活动日历。

### MOTDES · Motion design portfolio UI
一套 Astro + WebGL 动态作品集界面，包含流体背景、粒子 Profile、视频作品墙、服务案例、音效开关和滚动叙事。完整源码与媒体素材位于 `showcase/motdes/motdes/`。

运行 MOTDES：

```bash
cd showcase/motdes/motdes
npm install
npm run dev
```

每个案例的展示图、源码和规格说明独立归档，方便后续继续添加 UI。
